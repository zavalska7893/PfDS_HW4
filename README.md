# PfDS_HW4

## Опис виконаної роботи

У межах домашнього завдання реалізовано проєкт для роботи з реляційною базою даних MySQL у Docker-середовищі. Налаштовано автоматичне створення бази даних, таблиці та завантаження реального датасету Titanic через SQL-скрипт.

Проєкт містить:

* docker-compose.yml для запуску MySQL 8.0;
* init.sql для автоматичної ініціалізації бази даних;
* titanic.csv із даними пасажирів;
* main.py для підключення до бази даних та зчитування інформації через pandas.

## Реалізовано:

* запуск MySQL-контейнера через Docker Compose;
* healthcheck для перевірки готовності бази;
* автоматичне завантаження CSV-файлу через LOAD DATA INFILE;
* обробку NULL-значень для Age, Cabin та Embarked;
* підключення до MySQL через SQLAlchemy;
* retry-логіку при очікуванні готовності бази даних;
* виведення таблиці Titanic у вигляді pandas.DataFrame.

## Інструкція запуску

### Запуск Docker-контейнера

```bash id="p9e6q5"
docker compose up -d
```

### Запуск Python-скрипта

```bash id="lz4p5z"
python main.py
```

## Очікуваний результат

У терміналі відображається таблиця Titanic з 891 рядком і 12 колонками.

## Відомі обмеження

Для коректної роботи необхідно, щоб Docker Desktop та Docker Compose були встановлені локально.
